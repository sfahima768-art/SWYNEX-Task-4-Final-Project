# SWYNEX Final Data Analytics Project

## 1. Problem Statement
The objective of this project is to analyze student data and identify useful patterns in student age and marks.

## 2. Dataset Information
The dataset contains student IDs, ages, and marks.

## 3. Data Cleaning
The dataset was checked for missing values and cleaned to improve data quality.

## 4. Data Analysis
Exploratory Data Analysis (EDA) was performed using Python.

## 5. Visualizations
Charts were created to understand the distribution of student data and relationships between numerical variables.

## 6. Key Business Insights
- Student age and marks were analyzed.
- Missing values were checked during data cleaning.
- Charts help identify patterns in the dataset.

## 7. Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 8. Conclusion
This project demonstrates data cleaning, analysis, and visualization using Python.
